# Пульт для ПК

Телефон на Android управляет компьютером с Windows. Два способа связи:

* **Bluetooth** — телефон притворяется клавиатурой и мышью. На компьютере ничего ставить не нужно (подходит для вуза).
* **Wi-Fi** — программа `PultServer.exe` на компьютере + приложение. Работает только внутри локальной сети.

Папки: `android/` (Kotlin, без XML и библиотек), `server/` (Python), `.github/workflows/build.yml` (сборка в GitHub Actions).

## Протокол Wi-Fi (версия 1)

TCP, порт по умолчанию 8765. Каждое сообщение — одна строка JSON, заканчивается `\n`.

1. Телефон: `{"v":1,"t":"hello","code":"123456"}`
2. Компьютер: `{"ok":true,"v":1,"name":"MY-PC"}` или `{"ok":false,"err":"BAD_CODE"}`

Коды ошибок: `BAD_CODE` (неверный код), `LOCKED` (5 неудачных попыток — подожди минуту), `NOT_LOCAL` (не домашняя сеть), `BAD_VERSION`, `BAD_MESSAGE`.

После этого команды (все с `"v":1`):

| Что | Сообщение |
|---|---|
| Курсор | `{"t":"move","dx":5,"dy":-3}` |
| Кнопка мыши | `{"t":"btn","b":1,"down":true}` (1 левая, 2 правая) |
| Прокрутка | `{"t":"scroll","n":2}` (больше нуля — вверх) |
| Клавиша | `{"t":"key","k":"ctrl+c"}` |
| Текст | `{"t":"text","s":"привет"}` |
| Медиа | `{"t":"media","k":"playpause"}` (`next`, `prev`, `volup`, `voldown`, `mute`) |

Клавиши: стрелки `left right up down`, `enter esc tab space backspace delete home end pgup pgdn`, `f1`–`f12`, буквы, цифры; модификаторы `ctrl shift alt win` через `+`.

Безопасность: сервер принимает только адреса частных сетей, проверяет код при каждом подключении, не более 300 сообщений в секунду, выполняет только команды из списка выше.

## Настройки сервера

Файл `settings.json` рядом с `PultServer.exe`: `port` и `code`. Код можно сменить из меню значка.
