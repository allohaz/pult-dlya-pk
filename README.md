# Пульт для ПК

Телефон на Android управляет компьютером с Windows. Два способа связи:

* **Bluetooth** — телефон притворяется клавиатурой и мышью. На компьютере ничего ставить не нужно (подходит для вуза).
* **Wi-Fi** — программа `PultServer.exe` на компьютере + приложение. Работает только внутри локальной сети.

Папки: `android/` (Kotlin, без XML и библиотек), `server/` (Python), `.github/workflows/build.yml` (сборка в GitHub Actions).

## Протокол Wi-Fi (версия 1)

TCP, порт по умолчанию 8765. Каждое сообщение — одна строка JSON, заканчивается `\n`.

1. Телефон: `{"v":1,"t":"hello","code":"123456"}`
2. Компьютер: `{"ok":true,"v":1,"name":"MY-PC"}` или `{"ok":false,"err":"BAD_CODE"}`

Коды ошибок: `BAD_CODE` (неверный код), `LOCKED` (5 неудачных попыток — подожди минуту), `NOT_LOCAL` (не домашняя сеть), `BAD_VERSION`, `BAD_MESSAGE`.

После этого команды (все с `"v":1`):

| Что | Сообщение |
|---|---|
| Курсор | `{"t":"move","dx":5,"dy":-3}` |
| Курсор в точку экрана | `{"t":"abs","x":0.5,"y":0.2}` (от 0 до 1) |
| Кнопка мыши | `{"t":"btn","b":1,"down":true}` (1 левая, 2 правая) |
| Прокрутка | `{"t":"scroll","n":2}` (больше нуля — вверх) |
| Клавиша | `{"t":"key","k":"ctrl+c"}` (одна `win` — просто клавиша Win) |
| Текст | `{"t":"text","s":"привет"}` |
| Медиа | `{"t":"media","k":"playpause"}` (`next`, `prev`, `volup`, `voldown`, `mute`) |
| Система | `{"t":"system","a":"lock"}` (`lock`, `sleep`, `shutdown`, `restart`, `cancel`) |
| Моя кнопка | `{"t":"custom","id":0}` |
| Отправить на ПК | `{"t":"share","s":"https://..."}` (ссылка откроется, текст попадёт в буфер) |
| Буфер в ПК / из ПК | `{"t":"clip_set","s":"..."}` / `{"t":"clip_get"}` |
| Экран ПК | `{"t":"screen","on":true,"q":2}` (качество 1–3) |
| Игра: клавиша зажать/отпустить | `{"t":"keyd","k":"w","down":true}` (буквы, цифры, `space shift ctrl alt tab esc enter`, стрелки, `f1`–`f12`) |
| Игра: камера (относительная мышь) | `{"t":"gmove","dx":12,"dy":-4}` |
| Игра: кнопка мыши | `{"t":"gbtn","b":1,"down":true}` |

Ответы компьютера после входа: `{"t":"frame","d":"<JPEG в base64>","cx":0.4,"cy":0.7}` (кадр и положение курсора), `{"t":"clip","s":"..."}`, `{"t":"shared","s":"..."}`, при ошибке команды `{"ok":false,"err":"BAD_MESSAGE"}`.

Ответ на `hello` ещё содержит список «моих кнопок»: `"buttons":[{"id":0,"name":"Блокнот"}]`.

Клавиши: стрелки `left right up down`, `enter esc tab space backspace delete home end pgup pgdn`, `f1`–`f12`, буквы, цифры; модификаторы `ctrl shift alt win` через `+`.

Игровые команды идут через `SendInput` со сканкодами, как у настоящей клавиатуры и мыши. Если связь оборвалась, сервер сам отпускает все зажатые клавиши и кнопки. Игра, запущенная от имени администратора, не принимает ввод от обычной программы: запускай `PultServer.exe` тоже от администратора.

Безопасность: сервер принимает только адреса частных сетей, проверяет код при каждом подключении, не более 300 сообщений в секунду, выполняет только команды из списка выше.

## Настройки сервера

Файл `settings.json` рядом с `PultServer.exe` (открывается из меню значка: «Настройки и мои кнопки»):

* `port` и `code` — порт и код доступа (код можно сменить из меню значка);
* `buttons` — «мои кнопки». Пример: `{"name": "Папка", "open": "C:\\Users\\Me\\Documents"}`, `{"name": "Блокнот", "run": "notepad"}`. Команды из `run` выполняются только отсюда, телефон прислать их не может.

После правки файла просто переподключись с телефона, перезапускать программу не нужно.

Отправка на ПК: в любом приложении на телефоне «Поделиться» → «Пульт для ПК».
